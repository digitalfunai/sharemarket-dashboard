# Finora Share Market Dashboard

Open `index.html` in a modern browser. Internet access is required for Bootstrap, Bootstrap Icons, Chart.js, Google Fonts and the demo news image loaded through CDNs.

Main pages:
- `index.html` — interactive dashboard
- `pricing.html` — responsive pricing and billing toggle
- Other HTML files — themed starter routes

Keyboard shortcuts:
- `/` focus search
- `Alt + T` toggle theme
